Chạy dữ liệu

Kéo thả file .xlsx / .csv vào cửa sổ, hoặc chọn file / thư mục. File logic (Alert_Logic) phải là .xlsx. Có thể thêm từng file – app nhận diện theo nội dung, không theo tên.

Data (cập nhật hằng ngày)

Dữ liệu hằng ngày tự đến: bấm Sync (OneDrive) một lần ở các thư mục SharePoint chứa file nguồn của nhóm (danh sách bên dưới) – app tự tìm các file này trong thư mục OneDrive, tự tính Listing Issue và Current Stock, và tự lấy Activity Log từ Ads mỗi lần Chạy. File Data chỉ còn dùng cho Product Info, KPI (target), Summary. Không vào được thư mục (chỉ được chia sẻ từng file): bấm Add shortcut to My files ở từng file, rồi bấm Lấy file SharePoint một lần để đăng nhập – từ đó mỗi lần Chạy app tự tải file.

Claude Code

Khi Claude không sẵn sàng, app vẫn chạy rule và hiển thị cảnh báo; phần Insight / To-do / Rà soát logic sẽ trống. Dữ liệu gửi cho Claude chỉ là bảng tóm tắt alert, qua tài khoản Claude Code của bạn.

Ghi chú cho Claude

Claude đọc ghi chú này ở mọi lần chạy (phân tích, biên tập, rà soát logic, nhận xét đội, viết lại tin nhắn) và ưu tiên nó hơn các gợi ý khác.

Dữ liệu lịch sử (3 tháng)

Mỗi lần Chạy, app lưu số liệu theo ngày của raw_sso_us, ads_camp, INELIGIBLE ASIN và giữ 3 tháng gần nhất. File mới chỉ cần ~45 ngày: các ngày cũ hơn lấy từ đây (Performance Review, baseline Est GMV lost…). Ngày có trong file mới luôn thay số đã lưu.
